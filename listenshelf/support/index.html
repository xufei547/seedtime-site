Listenshelf Support

An audiobook player for the M4B and MP3 files you already own.

How do I add a book?

Tap + in the library. Import Files makes each file its own book. Import Folder as One Book turns every audio file in a folder into one book, ordered by file name. Files from Google Drive, Dropbox or OneDrive work when those apps are set up in the Files app.

The files of my book play in the wrong order

Touch and hold the book, choose Details and File Order, drag the files into the right order and tap Save.

My M4B shows no chapters

Listenshelf reads the chapter list stored inside the file. If the file has none, the book plays as one long track. Tools such as ffmpeg or Audiobook Builder can add chapters.

What is free?

Your first 2 books are free, with every feature and no time limits. Deleting a book does not give back a free one; importing the same book again is free. One purchase unlocks as many books as you like and is shared with your family. Books you imported always keep playing.

I bought the unlock on another device

Open Settings in Listenshelf and tap Restore Purchase, signed in with the same Apple Account.

Where are my files?

In the Files app under On My iPhone › Listenshelf › Audiobooks. You can copy them out at any time.

Can it play Audible or Apple Books audiobooks?

No. Those are protected (DRM). Listenshelf plays DRM-free files only.
